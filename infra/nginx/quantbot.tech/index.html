About QuantBot

Democratizing Institutional-Grade Analysis

QuantBot leverages the crewAI framework to orchestrate a hierarchy of specialized AI agents that collaborate to synthesize complex market data into actionable investment insights — the same caliber of analysis previously available only to Wall Street firms.

🕵

Hierarchical Multi-Agent System

Five specialized agents collaborate under a GPT-4.1 manager using crewAI's hierarchical process mode with memory persistence.

📈

Real-Time Financial Data

OHLC data, RSI calculations, intraday returns, earnings transcripts, and SEC 10-K filings — all automated.

🧠

NLP Sentiment Pipeline

Dual-source news analysis combining Alpha Vantage sentiment with SERP-based scraping, summarization, and zero-shot classification.

Research Contributions

Pushing Boundaries in AI Finance

QuantBot isn't just a tool — it's a research platform exploring the frontiers of multi-agent AI in financial analysis.

🎓

Hierarchical Agent Orchestration

Demonstrates how agent delegation and specialization can replicate institutional research workflows — a manager LLM coordinating specialist agents in real-time.

🧠

Financial NLP Pipeline

A novel combination of Falconsai summarization and zero-shot classification for financial news, producing bullish/bearish/neutral labels with confidence scoring.

📑

Automated SEC Filing Analysis

Bridging the gap between regulatory documents and AI analysis through automated 10-K parsing, chunking, and RAG ingestion for retrieval-augmented generation.

🔁

Hybrid Data Fusion

Combining structured financial data (OHLC, RSI) with unstructured data (news, 10-K filings, earnings transcripts) for holistic investment decisions.

🌐

Multi-Model Architecture

Supports both cloud (GPT-4.1) and local (Ollama Llama 3, Mistral) LLMs with graceful fallback, enabling research in resource-constrained environments.

🚀

Flow-Based Execution

Leverages crewAI's Flow framework with decorated methods for staged, deterministic pipeline execution — ensuring reproducibility in financial analysis.
