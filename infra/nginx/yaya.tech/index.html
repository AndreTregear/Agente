Layer 01

Hardware & Firmware

The trust anchor. Every Yaya node starts with verified, open-source firmware on inspectable hardware. No Intel ME. No hidden processors. No backdoors.

💻
ThinkPad Hardware Node
PHYSICAL COMPUTE UNIT
Refurbished ThinkPads (T440p, X230, T480) selected for Coreboot/Libreboot compatibility. Upgraded with SSDs and maxed RAM. The business owns this hardware outright. No leasing, no cloud dependency.
THINKPAD USER-OWNED SSD UPGRADE
🔧
Libreboot / Coreboot
OPEN-SOURCE FIRMWARE
Proprietary BIOS replaced with open-source firmware. Intel Management Engine neutered — no hidden remote access processor running below the OS. Firmware hash is the root of the attestation chain.
COREBOOT LIBREBOOT ME NEUTERED
📏
Measured Boot & Attestation
FIRMWARE INTEGRITY PROOF
Each boot measures firmware state into a cryptographic chain. This measurement becomes the basis for remote attestation — proving to peers on the .yaya mesh that this node's firmware is genuine and unmodified. Initially uses TPM 2.0, transitioning to the Yaya RoT chip.
TPM 2.0 → YAYA ROT PCR MEASUREMENTS BOOT CHAIN
⚙️
Yaya Root of Trust PCIe Chip
CUSTOM SILICON — TPM REPLACEMENT
A custom PCIe security module designed by Yaya.tech, manufactured via Seeed Studio. Replaces the TPM entirely with a sovereign root of trust that Yaya controls end-to-end. Combines three functions in one chip: (1) hardware root of trust and measured boot attestation, (2) post-quantum cryptography acceleration — hardware-accelerated Classic McEliece + Kyber key encapsulation, and (3) ZKP proof generation offload. By moving PQE key encapsulation to dedicated silicon, the mesh scales without CPU overhead bottlenecks. Each handshake becomes near-instant regardless of node count.
PCIE 3.0 SEEED STUDIO PQE ACCELERATOR ZKP OFFLOAD CUSTOM ASIC SOVEREIGN SILICON
🐧
Hardened Linux OS
OPERATING SYSTEM
Minimal Linux distribution with full-disk encryption (LUKS), mandatory access control (SELinux/AppArmor), automatic security updates, and sandboxed application containers. User holds the LUKS key. Not even Yaya can access their data.
LUKS SELINUX CONTAINERS AUTO-UPDATE

ZKP Attestation Circuit
PRIVACY-PRESERVING VERIFICATION
The ZK circuit proves: (1) firmware hash matches known-good Coreboot build, (2) OS version ≥ minimum required, (3) security patches are current, (4) no known compromised software present. All without revealing the actual firmware hash, OS version, or software list. On nodes with the Yaya RoT chip, proof generation is hardware-accelerated — sub-millisecond attestation at scale.
ZK-SNARKS GROTH16 CIRCOM

Cryptographic Identity
USER-HELD KEYPAIR
Each business holds an Ed25519 keypair generated locally on their ThinkPad. This is their identity. No centralized identity provider. No government database. The private key never leaves the device. The public key is their address on the .yaya network.
ED25519 LOCAL KEYGEN PKI
🚫
Compromised Node Exclusion
SELF-HEALING MESH SECURITY
A node with tampered firmware, outdated software, or a failed ZKP proof cannot complete the handshake. It is automatically excluded from the mesh. No manual intervention needed. The network heals itself by rejecting compromised participants.
AUTO-EXCLUDE SELF-HEALING ZERO TRUST

CoreDNS — Local Instance
PER-NODE DNS SERVER
Each ThinkPad runs a CoreDNS instance resolving the business's internal domain. Never leaves the machine. Other devices on the business's local WiFi can point to the ThinkPad as DNS resolver to access internal services.
COREDNS LOCAL ZONE MDNS

CoreDNS — Global .yaya
AUTHORITATIVE NAMESERVER
Yaya's central server runs the authoritative DNS for the .yaya zone. Resolves inter-business domains to Tailscale/Headscale mesh IPs (100.64.x.x). Acts as a private TLD visible only to authenticated mesh participants.
COREDNS AUTHORITATIVE PRIVATE TLD

DNS Registration Flow
AUTOMATIC DISCOVERY
When a new ThinkPad joins the mesh via Headscale, it registers its chosen .yaya domain. The domain is cryptographically bound to the business's keypair — no one else can claim it. Resolution is automatic for all mesh peers.
AUTO-REGISTER KEY-BOUND DNSSEC

Layer 08

Build Roadmap

From proof of concept with 3 ThinkPads to sovereign infrastructure for Peru's SMB economy.

PHASE 1 — NOW
Proof of Concept (3 ThinkPads)
Deploy Headscale on the free Kamatera server. Configure WireGuard mesh between 3 librebooted ThinkPads. Set up CoreDNS with Level 1 (local) and Level 2 (.yaya) resolution. Install basic ERP stack (ERPNext containers). Validate the full stack works end-to-end. Test exit node routing and remote access via phone.
PHASE 2 — MONTH 2-3
Rosenpass + Attestation Integration
Integrate Rosenpass sidecar with WireGuard for post-quantum key exchange. Build the firmware attestation module using TPM PCR measurements. Develop the ZKP attestation circuit (Circom/Groth16) for privacy-preserving compliance verification. Test the full trust handshake flow between nodes.
PHASE 3 — MONTH 3-4
Yaya App MVP
Build mobile app with WireGuard VPN client + .yaya DNS resolver. One-tap connect to business mesh. Basic dashboard showing business metrics from ThinkPad. Push notifications for sales, inventory alerts, WhatsApp agent activity.
PHASE 4 — MONTH 5-6
First Paying Customers
Deploy librebooted ThinkPads to 5-10 SMBs in Cañete/Lima. Full software stack: ERP, POS, WhatsApp AI agent, file storage. Onboard them to .yaya mesh. Collect feedback, iterate on UX. Establish monthly service fee billing.
PHASE 5 — MONTH 7-12
Marketplace & Payments
Launch mercado.yaya — federated B2B marketplace. Businesses discover each other, list products, transact. Integrate Yape/Plin on/off ramps. Build reputation system based on cryptographic transaction history. Identity layer for mesh-native business verification.
PHASE 6 — YEAR 2+
Scale & Sovereignty
Regional exit nodes for performance. Yaya Root of Trust PCIe chip manufactured with Seeed Studio — custom silicon replacing TPM with sovereign attestation, hardware-accelerated PQE key encapsulation (McEliece + Kyber), and ZKP proof generation offload. This chip is the scaling breakthrough: as the mesh grows to thousands of nodes, PQE handshakes that would bottleneck CPUs are handled by dedicated silicon at wire speed. Expand beyond Peru to Latin America. Open-source the stack for community-run .yaya meshes. The infrastructure becomes a public good.
